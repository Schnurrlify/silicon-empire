# Silicon Dynasty

Technologie-Tycoon-Spiel von Schnurrlify. Gründe eine Elektronikfirma, entwirf Geräte, bau Fabriken und setz dich gegen die grossen Marken durch.

**Webseite:** https://silicondynasty.ch

## Herunterladen

Das Spiel ist in der Beta und in dieser Zeit gratis.

- **Windows 10 und 11:** [SiliconDynasty-Setup.exe](https://github.com/Schnurrlify/silicon-empire/releases/latest/download/SiliconDynasty-Setup.exe)
- Alle Versionen: [Releases](https://github.com/Schnurrlify/silicon-empire/releases)

Zeigt Windows beim Start des Setups «Der Computer wurde durch Windows geschützt», klicke auf «Weitere Informationen» und dann auf «Trotzdem ausführen». Deine Spielstände bleiben bei Updates erhalten.
